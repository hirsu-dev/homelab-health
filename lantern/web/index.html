What do these numbers mean?

Observed reachability counts checks that connected, including slow checks. Coverage compares observed time buckets with scheduled buckets. Missing checks are not counted as successful uptime. A stale latest result becomes unknown after two check intervals.

Each history tile shows the worst observed state in that time bin; an empty bin is unknown. Incident end times are observed sample times. A coverage gap closes an incident as unobserved, never as a confirmed recovery. The local API returns up to 20 recent incidents per service.

A TCP connection confirms that a port accepted a connection, not that the application behind it is healthy. HTTP checks require a 2xx status and do not follow redirects. No response bodies, endpoint addresses or exception strings are included in this report.
